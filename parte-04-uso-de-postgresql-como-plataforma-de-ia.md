# Parte 4: Uso de PostgreSQL como Plataforma de IA

En la cuarta parte del libro, aprenderás sobre los requisitos específicos de la IA y cómo se pueden abordar con PostgreSQL. Te mostraremos cómo manejar el lenguaje natural como entrada y salida, y cómo combinar datos SQL con datos semánticos utilizando vectores y *embeddings*. `pgvector` es la herramienta preferida de PostgreSQL para representar información semántica, y te enseñaremos cómo usarla para habilitar la búsqueda semántica, construir motores de recomendación y extender modelos de razonamiento simples a herramientas multimodales que admitan capacidades avanzadas de Generación Aumentada por Recuperación (*Retrieval Augmented Generation* o RAG).

Capítulos separados se centran en la integración con Modelos de Lenguaje Grande (*Large Language Models* o LLMs) para generar *embeddings* de IA, construir arquitecturas de canalización sólidas y aprovechar el Protocolo de Contexto de Modelo (*Model Context Protocol* o MCP) para crear aplicaciones de IA confiables, auditables y seguras.
